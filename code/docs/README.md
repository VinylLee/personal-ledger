# 开发文档

本目录记录「收支账本」的内部实现、开发流程和变更历史，主要面向后续接手本项目的开发者与 AI Agent。

## 先读什么

| 文档 | 内容 | 什么时候读 |
|---|---|---|
| [ARCHITECTURE.md](ARCHITECTURE.md) | 数据流、模块职责、数据库结构、`decisions` 规则格式、统计口径、界面结构 | 动手改代码之前 |
| [DEVELOPMENT.md](DEVELOPMENT.md) | 环境、命令、无界面测试方法、修改检查清单、常见坑 | 搭建环境、写代码、验证时 |
| [CHANGELOG.md](CHANGELOG.md) | 按日期记录的变更 | 想了解最近改了什么 |

用户使用说明在上级目录的 [README.md](../README.md)。

## 维护规则（重要）

本项目已纳入 Git（远程 `VinylLee/personal-ledger`），但 `docs/CHANGELOG.md` 仍是主要的变更记录。因此：

1. 任何影响行为、数据结构、命令行参数、`decisions` 格式或界面操作的修改，都必须在同一次改动里更新本目录文档。
2. 架构或数据流变化改 `ARCHITECTURE.md`；命令、测试方法、易错点变化改 `DEVELOPMENT.md`；每次改动都在 `CHANGELOG.md` 追加一条。
3. 只改文案或样式且不影响行为的，可只记 `CHANGELOG.md`。
4. 文档中的路径、函数名、表名必须可在代码中检索到，不要凭记忆写。

## 项目一句话

把支付宝、微信、工行、建行的导出账单合并为一份 SQLite 账本，经过规则分类和人工复核后，提供报表、明细查询、图表和桌面界面。本地优先、单机运行；仅桌面汇总的汇率折算会可选访问公开汇率接口，不发送账本数据。
